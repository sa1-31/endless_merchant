# Endless Merchant Web App 🛒

This repository contains a **fully functional Endless Merchant web application** built as part of the **Endless Bi-Weekly Developer Contribution Program**.  

It’s a modern e-commerce style interface with **products, cart, orders**, and a **wallet integration simulation**. The app is designed to showcase frontend skills, DOM manipulation, and UI/UX design using **vanilla HTML, CSS, and JavaScript**.

---

## 🚀 Features

- **Products Display**: Shows multiple Endless and Nessy branded items with images, names, and EDS prices.  
- **Cart Management**: Add products to the cart, see live **cart count** in navbar, update quantities automatically.  
- **Orders System**: Confirm orders through a **transaction modal**, grouped products with quantities, order history display.  
- **Wallet Simulation**: “Connect Wallet” button to simulate connecting a blockchain wallet.  
- **Responsive Design**: Works seamlessly on **desktop and mobile**.  
- **Neon UI Theme**: Modern dark mode with neon highlights for buttons and headers.

---

## 🛠 Tech Stack

- **HTML5** – Semantic markup for the app structure.  
- **CSS3** – Responsive and modern styling, neon effects, flex/grid layouts.  
- **JavaScript** – DOM manipulation, cart & order logic, modal handling.  
- **Images** – Placeholder assets for Endless and Nessy product lines.
